# Titanic Survival Prediction 🚢

A machine learning project using the Titanic dataset from [Kaggle](https://www.kaggle.com/competitions/titanic?utm_source=chatgpt.com) to predict passenger survival.

## 🔧 Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

## 📊 Features Used

* Passenger Class
* Gender
* Age
* Fare
* Embarked

## 🚀 Workflow

1. Data Cleaning
2. Feature Engineering
3. Model Training
4. Prediction Generation

## 📈 Model Accuracy

| Model               | Accuracy |
| ------------------- | -------- |
| Logistic Regression | 80%      |
| Decision Tree       | 78%      |
| Random Forest       | 84%      |
| SVM                 | 82%      |

> Random Forest performed the best for this project.
